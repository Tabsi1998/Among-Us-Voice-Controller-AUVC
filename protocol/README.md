# Capture to bot protocol

Reserved for AUVC's shared versioned protocol, schemas, fixtures and compatibility
tests. Protocol v1 is a design target; no AUVC transport is implemented yet.

See [architecture](../docs/architecture.md) and
[requirements](../docs/requirements.md#protocol-pairing-and-recovery).
The existing upstream transports remain inside `bot/` and `capture/` until
the dedicated protocol and transport phases.
